# 🎤 Fix: Speech Recognition Matching & Mobile Detection

## Problem

**Logs show:**
```
Expected: "pehn-sahbah" (phonetic)
Heard: "Pensaba" (original Spanish word)
Result: 0% match ❌
```

The user pronounced it correctly, but the app didn't recognize it because:
1. Speech recognition returns the **original word** ("Pensaba")
2. App compares it to **phonetic spelling** ("pehn-sahbah")
3. They don't match despite being the same word

## ✅ Solution 1: Match Against Both Original AND Phonetic

### Update pronunciation-utils.ts

Add a function to check both the original word and phonetic:

```typescript
// pronunciation-utils.ts

/**
 * Calculate accuracy with support for matching against original word
 * Handles cases where speech recognition returns "Pensaba" but phonetic is "pehn-sahbah"
 */
export function calculateAccuracyWithOriginal(
  expectedPhonetic: string,
  expectedOriginal: string | undefined,
  actualTranscript: string
): number {
  if (!actualTranscript) return 0;

  // Strategy 1: Try matching against phonetic representation
  const phoneticScore = calculateAccuracy(expectedPhonetic, actualTranscript);
  
  console.log('[Accuracy] Phonetic match:', {
    expected: expectedPhonetic,
    actual: actualTranscript,
    score: phoneticScore
  });

  // Strategy 2: If original word provided, try matching against it
  if (expectedOriginal) {
    const originalScore = calculateAccuracy(expectedOriginal, actualTranscript);
    
    console.log('[Accuracy] Original match:', {
      expected: expectedOriginal,
      actual: actualTranscript,
      score: originalScore
    });

    // Take the BEST score from either phonetic or original
    const bestScore = Math.max(phoneticScore, originalScore);
    
    console.log('[Accuracy] Best score:', bestScore, '(from', 
                bestScore === phoneticScore ? 'phonetic' : 'original', 'match)');
    
    return bestScore;
  }

  return phoneticScore;
}

/**
 * Normalize Spanish/French text by removing accents for comparison
 */
function removeAccents(text: string): string {
  return text
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '') // Remove diacritical marks
    .toLowerCase();
}

/**
 * Enhanced accuracy calculation for international languages
 */
export function calculateAccuracy(expected: string, actual: string): number {
  if (!expected || !actual) return 0;
  
  // Normalize both strings (remove accents, punctuation, etc.)
  const normalizedExpected = normalizeForComparison(expected);
  const normalizedActual = normalizeForComparison(actual);
  
  // Also try without accents for Spanish/French words
  const expectedNoAccents = removeAccents(expected);
  const actualNoAccents = removeAccents(actual);
  
  // Perfect match (with or without accents)
  if (normalizedExpected === normalizedActual || 
      expectedNoAccents === actualNoAccents) {
    return 100;
  }
  
  // Try phonetic simplification
  const expectedSimple = phoneticToSounds(expected);
  const actualSimple = phoneticToSounds(actual);
  
  if (expectedSimple === actualSimple) {
    return 100;
  }
  
  // Calculate Levenshtein distances for multiple strategies
  const strategies = [
    { name: 'normalized', expected: normalizedExpected, actual: normalizedActual },
    { name: 'no-accents', expected: expectedNoAccents, actual: actualNoAccents },
    { name: 'phonetic', expected: expectedSimple, actual: actualSimple },
  ];
  
  let bestScore = 0;
  
  for (const strategy of strategies) {
    const distance = levenshteinDistance(strategy.expected, strategy.actual);
    const maxLen = Math.max(strategy.expected.length, strategy.actual.length);
    const score = maxLen > 0 ? Math.max(0, 1 - (distance / maxLen)) : 0;
    
    if (score > bestScore) {
      bestScore = score;
      console.log(`[Accuracy] Best strategy so far: ${strategy.name} (${Math.round(score * 100)}%)`);
    }
  }
  
  // Prefix bonus (first 3 chars match)
  const prefixLen = Math.min(3, expectedNoAccents.length, actualNoAccents.length);
  const prefixMatch = expectedNoAccents.substring(0, prefixLen) === 
                      actualNoAccents.substring(0, prefixLen);
  if (prefixMatch) {
    bestScore = Math.min(1.0, bestScore + 0.15);
  }
  
  // Contains check (one word contains the other)
  if (expectedNoAccents.includes(actualNoAccents) || 
      actualNoAccents.includes(expectedNoAccents)) {
    const shorter = Math.min(expectedNoAccents.length, actualNoAccents.length);
    const longer = Math.max(expectedNoAccents.length, actualNoAccents.length);
    const containsScore = shorter / longer;
    bestScore = Math.max(bestScore, containsScore);
  }
  
  const percentage = Math.round(bestScore * 100);
  
  console.log('[Accuracy] Final score:', percentage + '%', {
    expected,
    actual,
    normalizedExpected,
    normalizedActual
  });
  
  return percentage;
}
```

```typescript
    phonetic: currentWord.word,

  // Update word state
  const newWordStates = [...wordStates];
  newWordStates[wordIndex] = {
    ...currentWord,
    status: accuracy >= 60 ? 'success' : 'error',
    attempts: currentWord.attempts + 1,
    bestScore: Math.max(currentWord.bestScore || 0, accuracy)
  };
  setWordStates(newWordStates);

  // Show score banner
  setLastScore(accuracy);
  setShowScoreBanner(true);
  
  // Hide banner and advance

    clearTimeout(scoreBannerTimeoutRef.current);

  scoreBannerTimeoutRef.current = setTimeout(() => {
    setShowScoreBanner(false);
    setLastScore(null);

    if (autoAdvanceTimeoutRef.current) {
      clearTimeout(autoAdvanceTimeoutRef.current);

      setCurrentWordIndex(wordIndex + 1);
    }, hideDelay + 500);
```

## ✅ Solution 3: Improve Mobile Speech Recognition

### Issue: 8-second timeout with no speech detected

The logs show the mic times out without detecting speech. This is often due to:
1. Mic permissions
2. Language mismatch
3. Noise cancellation too aggressive
4. Low confidence threshold

### Fix Recognition Configuration

```typescript

const practiceWord = async (wordIndex: number) => {
```

## ✅ Solution 4: Handle Low Confidence Results

Sometimes speech recognition works but gives low confidence. Accept partial matches:

```typescript
// In speech recognition result handler

const handleSpeechResult = (results: string[]) => {
  if (!results || results.length === 0) {
    console.log('[Speech] No results');
    return;
  }

  console.log('[Speech] All results:', results);

  // Try to match against ANY of the results (in order of confidence)
  let bestMatch = { transcript: '', score: 0 };

  for (const transcript of results) {
    const score = calculateAccuracyWithOriginal(
      currentWord.word,
      currentWord.originalWord,
      transcript
    );

    console.log('[Speech] Testing:', transcript, '→', score + '%');

    if (score > bestMatch.score) {
      bestMatch = { transcript, score };
    }
  }

  console.log('[Speech] Best match:', bestMatch);

  // Use the best scoring result
  handlePronunciationResult(bestMatch.transcript, wordIndex);
};
```

## ✅ Solution 5: Fallback to Web Speech API

If Capacitor speech recognition is unreliable, fall back to web:

```typescript
const practiceWord = async (wordIndex: number) => {
  // ... setup code ...

  try {
    // Try Capacitor first
    if (Capacitor.isNativePlatform()) {
      try {
        await startCapacitorRecognition(wordIndex);
      } catch (capacitorError) {
        console.warn('[Practice] Capacitor failed, trying web:', capacitorError);
        // Fall back to web
        await startWebRecognition(wordIndex);
      }
    } else {
      await startWebRecognition(wordIndex);
    }
  } catch (error) {
    // Handle error
  }
};

async function startWebRecognition(wordIndex: number) {
  const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
  
  if (!SpeechRecognition) {
    throw new Error('Speech recognition not supported');
  }

  const recognition = new SpeechRecognition();
  const translation = translations.find(t => 
    t.originalText === lyrics[practiceLineIndex]?.text
  );
  const sourceLanguage = translation?.sourceLanguage || 'en';
  
  recognition.lang = sourceLanguage + '-' + sourceLanguage.toUpperCase();
  recognition.maxAlternatives = 5;
  recognition.continuous = false;
  recognition.interimResults = true;

  recognition.onresult = (event) => {
    const results = Array.from(event.results[0])
      .map((result: any) => result.transcript);
    
    handleSpeechResult(results);
  };

  recognition.start();
  console.log('[Web Speech] Started');
}
```
